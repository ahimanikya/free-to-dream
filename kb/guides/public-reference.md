# A dream others can build on

**World is One — A Poem Without Borders.** A poem about the freedom to dream becomes a shared place to learn, translate, make music and tell stories. We want the work to help the next poet, musician, filmmaker or curious listener as well as this collection.

## Start with the feeling, then listen to the language

1. Read the [Odia original](../poems/i-am-free-to-dream/original.md) and [meaning guide](../poems/i-am-free-to-dream/meaning.md). Protect the poem’s images, tenderness and invitation to weave dreams together.
2. Choose a [language page](../poems/i-am-free-to-dream/languages/index.md). Check whether it contains an original, draft adaptation, transcription pending or an adaptation brief. These are different stages, not a list of completed songs.
3. Read its musical reasoning. Name a local variety and specific influences, distinguish sourced tradition from creative interpretation, and leave room for other practices within the same language.
4. Begin with the [shared baseline](generation-settings.md). Document any local or arrangement override, why it helps, and how a listener should assess it. A common intention can produce many musical forms.
5. Ask a fluent speaker to check meaning and sung diction; ask a musician to check phrasing and context. Publish reviewer scope and unresolved questions. A style prompt describes an intention, not proof of an audible result.
6. Retain exact take IDs, actual controls, source hashes and credits. Use [take-specific timed lyrics](timed-lyrics.md) for video; do not stretch a soundtrack to fit guessed captions.

## For musicians and filmmakers

Use the licensed poem and reference material as a starting point for your own adaptation, performance or film. If you want an existing recording as a soundtrack, check its separate permissions first. A new setting can follow the poem’s mood while choosing its own ensemble, arrangement and imagery. Name your changes and collaborators.

The examples show decisions, not universal rules. This is an evolving community collection, not a pronunciation authority or an encyclopedia of every culture. Regional sources and lived expertise can correct or enrich a choice. [Contribute](contributing.md) through GitHub; suggestions remain reviewable before they become accepted source material.

## Read, download and cite

The website presents readable HTML; every language’s Markdown contains the full lyric prompt, cultural reasoning and review notes. The generated [reference data](https://poemwithoutborders.org/reference.json) lists all entries, readiness, intended settings, adopted overrides, source hashes and authorized current media. [llms.txt](https://poemwithoutborders.org/llms.txt) is a compact discovery index for tools that support it. Neither file certifies translation quality.

Cite the language page, Ahimanikya Satapathy as the original poet, named contributors, and the Git revision or Markdown SHA-256. Include your access date. The [repository history](https://github.com/ahimanikya/free-to-dream/commits/main/) preserves changes; generated data includes the build’s source revision when Git is available. The shared baseline is dated and model-specific, so future producers can understand the conditions rather than copy stale controls.

## Reuse with credit

Author-controlled poems, artwork and reference material are offered under **CC BY 4.0**; project code uses **MIT**. Recordings and third-party contributions have separate terms. Read the [scope and attribution guide](rights.md) before reusing an asset. Share your changes and experiences if you wish; contribution back is welcomed, not a license requirement.

## Make the work discoverable

The site provides page-specific descriptions, canonical URLs, structured data, a [sitemap](https://poemwithoutborders.org/sitemap.xml), native-language poem tags and linked Markdown. See [discovery and indexing](discovery.md) for how this works and what remains outside our control.
