# Bhojpuri feedback — issue 1

[Suggestion by Vikash Kumar (@codevk)](https://github.com/ahimanikya/free-to-dream/issues/1).

Current: **बीच राह में भटक जाए के मनाही नइखे।**

Adopted: **बीच राह में हेरा जाए के मनाही नइखे।**

The Odia source says **ହଜି ଜିବାକୁ**, becoming lost. The current line conveys wandering or straying in the road context; the contributor proposes a more direct Bhojpuri expression for becoming lost. This is a useful precision improvement rather than a reversal of the poem's meaning.

The proposed replacement is prepared at both occurrences (Intro and Chorus) in `candidate-lyrics.txt`. All other words, voice directions and pauses are unchanged. The contributor's exact regional form is retained, not normalized into Hindi. This is one-line contributor feedback, not evidence that the whole poem has received fluent review.

**Status: author adopted and applied for publication.** The author instructed “publish it.” Both occurrences on the language page use the revised wording, with contributor credit and a note identifying the earlier words in the Duet and Playful recordings. Existing audio/video and historical production packets are unchanged. No issue reply, closure or new music generation is authorized by this update. The deployment result is tracked in GitHub Actions for the publication commit.
