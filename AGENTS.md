# Project instructions

This repository is the source of truth for World is One — A Poem Without Borders.

- For music preparation, generation, review or publication, read [the project skill](skills/poetry-to-music/SKILL.md). It takes precedence over stale personal copies of this same project skill.
- Read [portable workspace](kb/guides/portable-workspace.md) for cloud setup and [production history](production/README.md) before resuming a language. Never depend on a particular laptop path or chat memory.
- Preserve source poems, each language's cultural musical direction and author-selected recordings. Solo is the default for new arrangements; propose a reasoned duet option and wait for the author's choice.
- Record prompts, settings, candidates, selections, cultural reasoning and review status in the tracked project. Credentials, browser sessions, private evidence and scratch media stay outside Git.
- Preparation and documentation changes do not authorize generation credits. One chosen language means one candidate pair, then author review. Follow the selected-take pipeline only within its stated authorization.
- Use existing checks listed in README.md. Keep media in Git LFS. Do not publish unreviewed takes merely because their historical records exist in production/.
